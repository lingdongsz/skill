# 蓝鲸选品 API 参考索引

这是轻量入口文件。只在需要具体接口字段时，打开对应的模块文档；不要一次性读取所有接口文档。

## 通用约定

- 所有接口统一返回：`code`、`msg`、`data`、`timestamp`。
- `code` 为 `0` 或 `200` 通常表示成功。
- 所有 API 请求都需要 Authorization Token。
- 支持站点：`MLM`、`MLB`、`MLC`、`MLA`、`MCO`。

## 按任务选择文档

- 商品搜索、商品详情、评价、每日/月度数据、流量词反查：`api/items.md`
- 店铺搜索、店铺画像、店铺风控指标：`api/sellers.md`
- 热搜词、关键词趋势、关键词供需判断：`api/keywords.md`
- 目录链接、官链、跟卖商品、BSR 每日数据：`api/catalogs.md`
- 行业趋势、价格分布、销量历史、新品机会、竞争店铺/品牌/商品：`api/trends.md`
- 汇率、运费、利润测算相关字段：`api/rate-shipping.md`

## 常见路由

- 用户要“找商品/看竞品”：先看 `api/items.md`。
- 用户要“查店铺/找本土卖家/跨境卖家”：先看 `api/sellers.md`。
- 用户要“找关键词/蓝海词/热搜词”：先看 `api/keywords.md`。
- 用户要“找官链/看跟卖/看 BSR”：先看 `api/catalogs.md`。
- 用户要“判断类目能不能做/什么价格好卖/品牌垄断吗”：先看 `api/trends.md`。
- 用户要“算利润/换算汇率/估运费”：先看 `api/rate-shipping.md`。

## 输出字段取舍

回复用户时优先提炼业务结论。只有在用户要求字段说明、排错、写脚本或校验响应时，才引用具体字段表。
