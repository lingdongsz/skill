# 蓝鲸选品

Mercado Libre 选品调研工具。**先澄清意图再调用脚本**（API 消耗 1~10 积分/次，方向错浪费积分）。

## 前置要求

- Authorization Token（配置 `LJXP_TOKEN` 环境变量或用户提供）；**不要在回复中暴露 Token**
- 支持站点：`MLM`、`MLB`、`MLC`、`MLA`、`MCO`
- API 基础：`https://xpskills.lingdongsz.com/api`；脚本使用 Python 标准库

<br />

## 标准 9 步流程（严格顺序，打 ✅ 绝对不能跳）

```
Step1 确认需求 → Step2 选功能 → Step3 查参考文档 → Step4 调脚本拿数据
→ Step5 数据分析 → Step6 业务结论 → Step7 积分统计 → Step8 后续引导 → Step9（可选）问HTML
```

## Step1 意图澄清（查询前必读）

### 何时必须先提问（满足任一即不可直接执行）

- ❌ 未指定站点（MLM/MLB/MLC/MLA/MCO）
- ❌ 未指定类目或关键词
- ❌ 分析目标模糊（如"帮我看看市场"）
- ❌ 关键参数缺失（热搜词未给日期、趋势未给类目ID等）
- ❌ 多方向并存、优先级不明

### 何时可直接执行

站点 + 类目/关键词 + 分析目标 + 必要参数 齐全。

### 各分析类型必填参数清单

> **【类目树极其重要】** 后端 `GET /category/tree` **只接受 `siteId` 一个参数**。`--depth`/`--search`/`--refresh` 是脚本本地后处理，**绝对不能发给后端**。

| 分析类型 | 后端必填参数 | 脚本本地处理参数（不发后端） | 对应脚本 |
|---|---|---|---|
| 类目树查询/定位ID | 站点（siteId） | `--depth` `--search` `--refresh` | `category_tree.py` |
| 类目机会评估 | 站点、类目ID | — | `trends.py` |
| 价格带分析 | 站点、类目ID | 目标价格范围 | `trends.py`（--type price_list） |
| 关键词研究 | 站点、查询类型(day/month)、日期 | 类目ID、搜索词 | `search_keywords.py` |
| 竞品分析 | 站点、搜索条件(关键词/类目/店铺ID 至少其一) | 价格范围、销量范围、排序 | `search_items.py` |
| 店铺分析 | 站点、筛选条件(类型/等级/店铺ID 至少其一) | 具体店铺ID | `search_sellers.py` |
| 品牌格局分析 | 站点、类目ID | 关注品牌 | `trends.py`（--type top_brands） |
| 目录链接机会 | 站点、搜索条件(关键词/类目 至少其一) | 跟卖状态、价格范围 | `catalog_search.py` |
| 利润测算 | 站点、商品信息(价格/重量) | 成本、目标利润率 | `get_item_info.py` + 运费查询 |

> 类目 ID 格式如 `MLM458037`。只有品类名时优先 `category_tree.py --site <站点> --search <关键词>` 本地过滤定位（首次 10 积分，命中缓存免费，缓存 7 天，`--refresh` 强制刷新）。

## Step5 分析维度

## Step6 业务结论 6 要素

关键数据（核心指标一句话）｜ 机会等级（推荐/谨慎/暂不建议）｜ 主要风险（2-3条）｜ 推荐动作（明确下一步）｜ 筛选条件/脚本（可复现）｜ 需补充信息（如有）

| 商品查询 | 1 | 5 | 5 |

规则：
1. 只列本次实际调用的接口功能名（用各模块积分表的「功能描述」）

## 各分析流程（Step2 详细步骤，每个流程第一步均为「确认关键参数」）

### 类目树查询 / 定位类目 ID

1. **确认参数**：站点（必选）；只有品类名无 ID 时走本流程
2. 定位：优先关键词过滤，无关键词逐层浏览
3. 结果让用户核对中英文名称，ID 传给下游趋势/搜索/关键词/目录链接等流程

### 类目机会评估

1. **确认参数**：站点、类目ID（无ID先走类目树）
2. 查：行业趋势+价格分布+头部店铺+头部品牌+代表商品
3. 判断：市场容量/竞争强度/品牌集中度/本土跨境格局
4. 输出：推荐/谨慎/暂不建议 + 下一步（价格/关键词/竞品/上架策略）

### 价格带分析

1. **确认参数**：站点、类目ID（+目标价格范围如有）
2. 查价格分布 → 对比各区间商品数和销量 → 找需求高供给少的价格带 → 拉热门商品验证
3. 输出：建议定价+避开价格带+参考商品

### 关键词研究

1. **确认参数**：站点、查询类型(day/month)、查询日期（+类目/搜索词如有）
2. 查热搜词 → 关注搜索量高/访问量高/销量好/商品数少的词 → 用商品搜索验证供给竞争
3. 输出：自然流量词+广告词+长尾词+不建议投入的词

### 竞品分析

1. **确认参数**：站点、搜索条件(关键词/类目ID/店铺ID 至少其一，推荐+价格范围/销量范围/排序)
2. 按条件筛选商品 → 对比价格/30天销量/评分/评论数/店铺类型/仓储/上架时间 → 查详情/评价/每日月度数据/流量词
3. 输出：爆款共性+用户痛点+差异化机会+风险

### 店铺分析

1. **确认参数**：站点、筛选条件(店铺类型/等级/优质卖家等级/店铺ID 至少其一)
2. 筛选店铺 → 查看商品数/销量/信用等级/取消率/延迟率/投诉率 → 按店铺ID查商品矩阵
3. 输出：对标店铺+经营模型+可学习点

### 品牌格局分析

1. **确认参数**：站点、类目ID（+关注品牌如有）
2. 查头部品牌 → 对比品牌数/活跃品牌数/Top品牌销量/销售额/均价 → 判断是否有强品牌壁垒
3. 输出：白牌机会+对标品牌+进入风险

### 目录链接机会

1. **确认参数**：站点、搜索条件(关键词/类目ID 至少其一，推荐+跟卖状态/价格范围/BSR范围)
2. 按条件筛选目录链接 → 查详情和跟卖商品 → 判断适合跟卖/差异化上架/竞品参考
3. 输出：机会链接+风险点+筛选条件

### 利润测算

1. **确认参数**：站点、商品信息(商品ID 或 价格+重量，推荐+成本/目标利润率；未给成本先问)
2. 取价格/重量/店铺类型/佣金/货币 → 查汇率运费 → 估算毛利/毛利率/价格安全区间
3. 明确说明测算假设
